## What this batch would add to the dataset

If all five produce, the dataset grows from 8 agencies sent to 13,
and gains: a Flock-misuse investigation file (Joplin), a second
southwest-Missouri county pair (Jasper), a metro county (Jackson),
the state's largest city (KCPD), and a completed Greene County pair.
That is the shape of a licensable cross-state report: Kansas 5 counties
+ Wichita (portal, next) vs. Missouri 5 counties + 2 cities + AG,
all scored on the same rubric — response time, fee, denial basis,
287(g) agreement / money, ALPR contract / retention / audit logs,
and EO 26-18 compliance.

## Cost

No new fees beyond the $50 ceiling already set for Missouri. Each
request asks for an itemized estimate before any work above $50, and
notes the § 610.026.2 90-day withdrawal clock.
